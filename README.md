# AITM Lost & Found

A Lost & Found web application built for the AITM Coding Club Member Screening Assessment.

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Supabase (Database & Storage)
- Vercel

---

## Features

- Report Lost Items
- Report Found Items
- Upload Item Images
- Browse Open Reports
- Search Items
- Filter by Lost / Found / Category
- View Item Details
- Edit Existing Reports
- Delete Reports
- Mark Items as Claimed
- Responsive Design
- Loading Skeletons & Empty States

---

## PROTOTYPE NOTES

This project is intentionally built **without authentication** to keep the prototype simple for the assessment.

Because of this:

- Anyone can submit reports.
- Anyone can edit reports.
- Anyone can delete reports.
- Anyone can mark items as claimed.
- Spam or fake reports are currently possible.

These actions would be protected in a production version using authentication and authorization.
